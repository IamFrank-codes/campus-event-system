## Interpretation

After running the test, use the P95 column to describe the upper-end response time observed during the workload. Report the request count, worker count, timeout, machine, deployment mode, and error rate alongside the results. Repeat the test with at least two worker settings, such as `--workers 1` and `--workers 5`, before making a scalability statement.

## How to generate the final results

From the project root in the VS Code terminal, while all five services are running, execute:

```bat
pip install requests
python performance_test.py --requests 50 --workers 5 --timeout 10
```

The script will overwrite this file with measured values and also create `performance_results.csv`.
